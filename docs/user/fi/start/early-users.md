# Lähde mukaan ensimmäisten joukossa

aggountant syntyi ajatuksesta, että agenttien aikakaudella kenenkään ei pitäisi
maksaa kirjanpidon kaltaisesta peruspalvelusta. Agentti voi hoitaa sen, ja
sinä hyväksyt. Tavoite on, että pieni suomalainen yritys hoitaa kirjanpitonsa
ja kaikki lakisääteiset ilmoituksensa alusta loppuun ilman tilitoimistoa,
muutaman vartin työllä kuukaudessa.

Tämä sivu on sinulle, jos haluat ottaa aggountantin käyttöön nyt, kun se on
vielä varhaisessa vaiheessa, tai kehittää sitä kanssamme.

## Mitä tarjoamme

- **Tapaamme.** Jos harkitset aggountantin käyttöönottoa omassa yrityksessäsi,
  voimme sopia tapaamisen ja käydä yrityksesi tilanteen läpi yhdessä.
- **Kehitämme sitä, mitä tarvitset.** Ominaisuudet syntyvät siitä, mihin
  käyttäjien kirjanpidossa törmätään. Kun sinun yrityksesi kohtaa tilanteen,
  jota aggountant ei vielä osaa, se nousee työjonoon.
- **Vastaamme nopeasti.** Kysymykset ja vikailmoitukset käsitellään yleensä
  päivien, ei viikkojen sisällä.

## Mitä toivomme

- **Kerro yrityksestäsi:** toimiala, koko, pankki ja miten kirjanpito hoidetaan
  nyt. Se auttaa päättämään, mitä tehdään seuraavaksi.
- **Kerro, mikä ei toimi.** Varhaisen käyttäjän tärkein apu on palaute
  oikeasta käytöstä.
- **Kehitä mukana.** aggountant on avointa lähdekoodia (MIT). Toivomme mukaan
  muitakin kehittäjiä, kirjanpitäjiä ja käyttäjiä parantamaan sitä
  avoimen lähdekoodin hengessä: koodia, ohjeita, korjauksia tai kokemuksia.
