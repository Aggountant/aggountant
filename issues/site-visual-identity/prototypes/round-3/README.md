# Round 3: how the agent's name appears in the hero (superseded)

The live hero's rotating agent name ("Hoida firmasi kirjanpito ___") looked
"vähän hönöltä" to Jari (12.11.2026). Round 3 tried three directions:

- **Lomakekenttä:** the name typed into a fixed-width form field in the
  headline.
- **Hiljainen:** a static headline, "omalla agentillasi", with the agents
  listed in small type beneath it.
- **Laatija:** a static headline, with the agent's name typed onto the
  voucher's LAATINUT line and "HYVÄKSYNYT Sinä" under it.

Jari picked Laatija but found the name too small and, on a phone, below the
first screen. Round 4 (`../round-4/`) riffs on Laatija with the `prototype`
skill's picker harness. The round-3 files were removed when round 4
replaced them; they are in git history at commit aa5c874.
